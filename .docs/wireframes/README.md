# Wireframes

Low-fidelity wireframes for every screen in `.docs/01-screen-inventory.md`. These are a **product specification**, not decoration: they define information hierarchy, content density, primary actions, and state behaviour. Visual design (colour, type, spacing) is specified separately in `.docs/06-design-system.md` and is deliberately absent here.

## Reading these

```text
┌──────────────────────────────────────────────┐   390 × 844 pt reference viewport
│ Header                                       │   (iPhone 13 / typical 6.1" Android)
├──────────────────────────────────────────────┤
│ Content                                      │
├──────────────────────────────────────────────┤
│ Bottom navigation (tabs only)                │
└──────────────────────────────────────────────┘

▸       tappable / navigates
🔗      source affordance — opens S-52 Source sheet
(?)     methodology explainer — opens S-57
▤       missing-data block
⚡      offline indicator
◔       verification-priority band glyph
[  ]    button
⋯       truncated for brevity in the wireframe, not in the product
```
