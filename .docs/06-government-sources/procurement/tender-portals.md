# Tender Portals

Tender publication and procurement systems are catalogued together in **[`.docs/06-government-sources/procurement/procurement-portals.md`](./procurement-portals.md)** — separating "procurement portals" from "tender portals" would split one system per row across two files.

That file covers:

- Central procurement systems (CPPP, ePublishing, GeM, GePNIC central, PMGSY e-procurement)
- All 36 State/UT procurement portals, with platform classification
- The GePNIC standard page structure shared by most States/UTs
- Stale entries found in the government's own published list
- Non-GePNIC states requiring bespoke connectors

Field-level analysis of what a tender record exposes is in **[`.docs/04-data-engineering/entity-linking.md`](../../04-data-engineering/entity-linking.md)** and **[`.docs/04-data-engineering/ingestion-methods.md`](../../04-data-engineering/ingestion-methods.md)**.
