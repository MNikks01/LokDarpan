## data.gov.in — the only confirmed general API

✅ `data.gov.in` is the Open Government Data Platform, and the only source in this registry confirmed to offer a general-purpose API with CSV/JSON/XML formats. It publishes a **Local Government Directory catalogue**.

**Per-dataset assessment has not been done.** §18 asks for dataset, publisher, URL, licence, format, API, update frequency, historical availability, coverage and identifiers **per dataset** — that is a substantial exercise against a catalogue of many thousands of datasets and is the natural next step for this source specifically.

**Not systematically identified.** A few states operate open-data portals; none was verified in this pass. They are the most likely route to structured state data and should be searched for explicitly per state.
